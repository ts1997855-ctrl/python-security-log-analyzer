# 🔐 Python Security Log Analyzer

A Python-based cybersecurity project that analyzes security log files, detects suspicious login activity, assigns severity levels, and generates security reports.

This project demonstrates practical skills in **Python programming, log analysis, security monitoring, incident detection, and security automation**.

---

## 🎯 Project Objective

The objective of this project is to demonstrate how Python can be used to automate basic security log analysis.

The program processes authentication log entries and identifies potentially suspicious activity such as repeated failed login attempts.

---

## ✨ Features

- Reads and analyzes security log files
- Detects successful login attempts
- Detects failed login attempts
- Identifies repeated failed-login activity
- Tracks suspicious activity by IP address
- Assigns severity levels to detected events
- Generates a security analysis report
- Demonstrates basic security monitoring automation
